📦 LDV – Logistics Document Validator — Guide / Hướng dẫn sử dụng

Checks a shipment's documents (Invoice/Packing List, Sales Contract, B/L, Form D) and produces a report. Documents are only read — never changed.
Kiểm tra bộ chứng từ lô hàng (Invoice/Packing List, Hợp đồng, B/L, C/O form D) và xuất báo cáo. Chứng từ chỉ được đọc — không bị sửa.

1. First-time setup / Cài đặt lần đầu

English

  1. Python 3.15 must be installed (per-user install, no admin).
  2. Copy the whole logistics-document-validator folder to your PC, e.g. Documents\logistics-document-validator.
  3. Double-click Setup.bat. It downloads the libraries (needs internet, a few minutes, once only).
  4. Wait for “Setup complete”, then press any key.

Tiếng Việt

  1. Máy đã cài Python 3.15 (cài cho riêng người dùng, không cần quyền admin).
  2. Chép nguyên thư mục logistics-document-validator vào máy, ví dụ Documents\logistics-document-validator.
  3. Bấm đúp Setup.bat. Chương trình tải thư viện (cần internet, vài phút, chỉ làm một lần).
  4. Chờ đến khi hiện “Setup complete”, rồi bấm phím bất kỳ.

2. Daily use / Sử dụng hằng ngày

English

  1. Double-click Start.bat. A black window opens and the browser shows the app. Keep the black window open while working.
  2. Drag in one shipment: the .zip file, or all its PDF files.
  3. Click Check documents.
  4. Read the findings. Click a finding to see the page screenshot.
  5. Click Download Excel report if you need to send it.
  6. To stop: close the black window.

Tiếng Việt

  1. Bấm đúp Start.bat. Một cửa sổ đen mở ra và trình duyệt hiện chương trình. Giữ cửa sổ đen mở trong lúc làm việc.
  2. Kéo thả một lô hàng: file .zip, hoặc tất cả file PDF của lô.
  3. Bấm Kiểm tra.
  4. Đọc kết quả. Bấm vào từng dòng để xem ảnh trang chứng từ.
  5. Bấm Tải báo cáo Excel nếu cần gửi đi.
  6. Tắt chương trình: đóng cửa sổ đen.
Language: use the left panel to choose English, Tiếng Việt or Both / Cả hai. You can also filter by severity there.
Ngôn ngữ: chọn ở khung bên trái. Có thể lọc theo mức độ lỗi tại đó.

3. Reading the report / Đọc báo cáo

Severity / Mức độMeaningÝ nghĩa
🔴 Error / LỗiDocuments disagree or numbers are wrong — must be amendedChứng từ không khớp hoặc số liệu sai — phải sửa
🟠 Warning / Cảnh báoRisky or non-standard — check and decideCó rủi ro hoặc chưa chuẩn — cần xem xét
🟡 Minor / Lỗi nhỏTyping / format issueLỗi đánh máy / trình bày
🔵 Info / Thông tinFor your informationThông tin tham khảo

Each finding shows: Current value, Suggested value, and screenshots — red box = value to check, green box = reference value.
Mỗi dòng gồm: giá trị Hiện tại, giá trị Đề xuất, và ảnh — khung đỏ = giá trị cần kiểm tra, khung xanh = giá trị tham chiếu.

Not recognised / Không đọc được: files or fields the tool could not read. Check those manually — the tool never silently skips them.
Các file hoặc trường không đọc được — hãy kiểm tra thủ công.

5. Updates / Cập nhật

Every time you start Start.bat, LDV checks GitHub for a new version. If there is one, the black window shows what is new and asks Update now? [Y/N]. Type Y and press Enter to update, or N to keep the current version for now. Without internet the check is skipped and the app starts normally. The version number is shown at the bottom of the left sidebar. Replaced files are kept in the _backup folder.

Mỗi lần chạy Start.bat, LDV kiểm tra phiên bản mới trên GitHub. Nếu có, cửa sổ đen hiển thị nội dung mới và hỏi Cap nhat ngay? [Y/N]. Gõ Y rồi Enter để cập nhật, hoặc N để dùng tiếp bản hiện tại. Không có mạng thì bỏ qua và chương trình chạy bình thường. Số phiên bản hiển thị ở cuối thanh bên trái. Các file cũ được lưu trong thư mục _backup.

6. Troubleshooting / Xử lý sự cố

Problem / Sự cốWhat to do / Cách xử lý
“Python not found” / “Chưa có Python”Install Python 3.15 from python.org (“Install Now”, untick admin option) / Cài Python 3.15 từ python.org, bỏ chọn tùy chọn admin.
Setup fails while installing libraries / Cài thư viện thất bạiInternet or company proxy is blocking downloads. Ask for the offline wheels folder, put it inside logistics-document-validator, run Setup.bat again. / Mạng hoặc proxy chặn tải. Xin thư mục wheels, đặt vào logistics-document-validator rồi chạy lại Setup.bat.
Browser did not open / Trình duyệt không tự mởOpen http://localhost:8501 manually / Mở thủ công địa chỉ trên.
“Port 8501 is already in use”The app is already running in another black window — use that one, or close it first / Chương trình đang chạy ở cửa sổ khác — dùng cửa sổ đó hoặc đóng lại.
A document is listed under Not recognised / Chứng từ nằm trong mục Không đọc đượcNew supplier layout or scanned PDF — check manually and send the file to the tool maintainer / Mẫu chứng từ mới hoặc bản scan — kiểm tra thủ công và gửi file cho người phụ trách công cụ.

Everything runs on this PC only (http://localhost). No document is uploaded to the internet. / Mọi xử lý chạy trên máy này. Không có chứng từ nào được gửi lên internet.
